# 打飞机微信小游戏

一个经典的射击类微信小游戏，玩家控制战机在星空中击落敌机，获得高分。

## 游戏特色

- 🚀 流畅的飞机控制和射击
- 💥 炫酷的爆炸特效和粒子系统
- 🎵 动态音效和背景音乐
- 📈 渐进式难度提升系统
- ⭐ 美丽的星空背景
- 🎮 专为微信小游戏优化

## 游戏玩法

- **移动**: 触摸屏幕并拖动来控制战机移动
- **射击**: 战机自动射击，无需手动操作
- **目标**: 击落尽可能多的敌机，获得高分
- **敌机类型**: 
  - 红色普通敌机 (10分)
  - 紫色快速敌机 (20分)

## 游戏系统

### 关卡系统
- 随着分数增加，游戏难度逐渐提升
- 敌机生成频率增加
- 分数倍率提升

### 特效系统
- 击中敌机的爆炸效果
- 粒子飞散效果
- 星星闪烁背景

### 音效系统
- 射击音效
- 爆炸音效
- 背景音乐
- 游戏结束音效

## 项目结构

```
airplane_game/
├── game.js                 # 游戏入口文件
├── game.json              # 微信小游戏配置
├── project.config.json    # 开发工具配置
├── js/
│   ├── main.js           # 主游戏类
│   ├── player.js         # 玩家飞机类
│   ├── enemy.js          # 敌机类
│   ├── bullet.js         # 子弹类
│   ├── background.js     # 背景类
│   ├── effects.js        # 特效类
│   ├── audio.js          # 音频管理类
│   ├── config.js         # 游戏配置
│   └── libs/
│       ├── weapp-adapter.js  # 微信适配器
│       └── symbol.js         # Symbol兼容
├── images/               # 图片资源（可扩展）
└── audio/               # 音频资源（可扩展）
```

## 开发说明

### 运行环境
- 微信开发者工具
- 支持ES6+语法
- Canvas 2D渲染

### 主要技术
- JavaScript ES6+ 模块化
- Canvas 2D API
- Web Audio API
- 微信小游戏API

### 性能优化
- 对象池管理（子弹、敌机复用）
- 及时清理超出屏幕的对象
- 高效的碰撞检测算法
- 音频资源复用

## 扩展建议

## 使用方法

1. 在微信开发者工具中打开项目
2. 编译运行
3. 在真机上预览测试

## 注意事项

- 确保在微信开发者工具中设置正确的AppID
- 音频功能需要用户首次交互后才能正常工作
- 建议在真机上测试触控和音效功能
