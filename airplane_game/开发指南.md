# 快速开始指南

## 1. 准备工作

### 安装微信开发者工具
1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册微信小程序开发者账号
3. 获取AppID（测试可以选择"测试号"）

## 2. 导入项目

1. 打开微信开发者工具
2. 选择"小游戏"
3. 点击"导入项目"
4. 选择 `airplane_game` 文件夹
5. 填入AppID（或选择测试号）
6. 项目名称：打飞机游戏

## 3. 配置项目

### 修改项目配置（可选）
编辑 `project.config.json` 文件：
```json
{
  "appid": "你的真实AppID",
  "projectname": "airplane_game"
}
```

### 游戏配置调整
编辑 `js/config.js` 文件可以调整：
- 游戏难度
- 敌机生成频率
- 分数系统
- 音效设置

## 4. 运行游戏

1. 在微信开发者工具中点击"编译"
2. 在模拟器中预览游戏
3. 点击"预览"在真机上测试

## 5. 游戏操作

- **开始游戏**: 加载完成后自动开始
- **控制飞机**: 触摸屏幕并拖动
- **射击**: 自动射击，无需操作
- **重新开始**: 游戏结束后点击屏幕

## 6. 调试技巧

### 查看日志
在微信开发者工具的"控制台"标签中查看游戏运行日志

### 性能监控
在"Network"和"Performance"标签中监控游戏性能

### 真机调试
使用"远程调试"功能在真机上调试

## 7. 自定义开发

### 添加新敌机类型
1. 在 `js/config.js` 中添加敌机配置
2. 在 `js/enemy.js` 中添加渲染逻辑
3. 在 `js/main.js` 中添加生成逻辑

### 添加道具系统
1. 创建 `js/powerup.js` 道具类
2. 在主游戏循环中添加道具逻辑
3. 实现道具效果

### 更换视觉资源
1. 在 `images/` 文件夹中添加图片
2. 修改各个类的 `render()` 方法
3. 使用 `wx.createImage()` 加载图片

### 添加音频文件
1. 在 `audio/` 文件夹中添加音频文件
2. 修改 `js/audio.js` 使用真实音频
3. 使用 `wx.createInnerAudioContext()` 播放

## 8. 发布游戏

1. 完善游戏内容和测试
2. 在微信公众平台提交审核
3. 通过审核后即可发布

## 9. 常见问题

### 音频不播放
- 确保用户已经与页面交互
- 检查音频文件路径
- 在真机上测试

### 触控不灵敏
- 调整 `js/player.js` 中的移动参数
- 在真机上测试触控效果

### 游戏卡顿
- 减少同时存在的对象数量
- 优化渲染逻辑
- 使用对象池技术

### 适配问题
- 检查 `js/libs/weapp-adapter.js`
- 调整 Canvas 尺寸适配
- 测试不同设备屏幕

## 10. 技术支持

如果遇到问题，可以：
- 查看微信小游戏官方文档
- 在微信开发者社区提问
- 查看项目的 README.md 文件
